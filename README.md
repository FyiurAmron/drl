# drl-lib
### A conversion of DRL into a DLL to facilitate a clean-room license-unencumbered rewrite in Godot & .NET 10 C#

Code is FreePascal with OBJFPC and Lazarus project files. Tested in full 64-bit setting.
1. open `src/drl.lpi`
2. compile + build
3. run via integration
